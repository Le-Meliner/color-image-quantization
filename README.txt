Compilation :make

Nettoyage : make clean

ppmhist : Affiche les n-uplets (R,G,B,lum,occ)
	  Commande : ./ppmhist <image_input.ppm>



quantif (programme final) : Prend K et l'image d'entrée, écrit l'image de sortie sur stdout (rediriger vers un fichier).
	Commande : ./quantif <nombre de couleur K> <image_input.ppm> > <image_output.ppm>
